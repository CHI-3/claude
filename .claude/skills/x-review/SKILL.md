# Multi Repo PR Review Skill

---
name: review  
description: 複数リポジトリのPRを横断レビューする（ルートおよび各repo直下のCLAUDE.mdを必ず参照）  
args:
  - name: targets
    description: "repo名:PR番号 repo名:PR番号 ... [NotionURL]"
    required: true
---

## 概要

claude ディレクトリ配下にある複数リポジトリの PR を取得し、必要に応じて Notion の開発要件と突き合わせたうえで、リポジトリごとにレビュー結果を出力する。

シェルスクリプトは使用しない。本スキル内の処理のみで完結させる。

---

## 前提構造

- ./claude/
  - CLAUDE.md
  - repo-a/
    - CLAUDE.md
  - repo-b/
    - CLAUDE.md
  - repo-c/
    - CLAUDE.md
  - ...

---

## 実行手順

### 1. 引数解析

targets を空白で分割する。

- repo名:PR番号 形式のトークンをすべて抽出する
- http で始まる文字列があれば NotionURL とみなす（最後の1つを採用）

### バリデーション

- repo指定が1つ以上あること
- ./claude/<repo名> が存在すること
- PR番号が数値であること

不備があれば明示して終了する。

---

### 2. CLAUDE.md 読み取り（必須）

1. ./claude/CLAUDE.md を読み取り、共通ルールを抽出する
2. 各 ./claude/<repo>/CLAUDE.md を読み取り、repo固有ルールを抽出する

抽出対象例:

- コーディング規約
- 設計方針
- 禁止事項
- レビュー優先事項
- 命名規則
- アーキテクチャ制約

抽出したルールはレビュー基準に必ず反映する。

---

### 3. Notion要件取得（URLがある場合のみ）

1. claude.ai Notion でページ本文取得を試行する
2. 失敗時は Notion純正MCP を試行する

取得できた場合、以下の観点で整理する:

- 機能要件
- 非機能要件
- 受入条件
- 制約条件
- 影響範囲
- 想定例外

取得できなかった場合はその旨を明示し、PR情報ベースのレビューへ切り替える。

---

### 4. PR情報取得（各repoごと）

作業ディレクトリ: ./claude/<repo名>

取得対象:

- PRタイトル
- PR本文
- 作者
- ラベル
- base/headブランチ
- 変更ファイル一覧
- 追加行数・削除行数
- PRコメント（レビューコメント含む）
- 差分

差分が大規模な場合は以下を優先確認する:

- 認証・認可関連
- DBスキーマ変更
- API変更
- 設定変更
- 共通モジュール変更
- CI設定変更
- 例外処理変更

未確認領域がある場合は明示する。

---

## レビュー観点

最低限確認する項目:

- 要件適合性（NotionまたはPR本文との整合）
- 仕様漏れ・例外処理
- セキュリティリスク
- パフォーマンス影響
- 他repoや外部連携への影響
- テスト妥当性
- 可読性・保守性
- CLAUDE.md遵守状況

---

## 出力形式

リポジトリ単位で出力する。

順序は入力順とする。

---

## 出力構造

## repo名（PR #番号）

要約:
- 変更の狙い:
- 要件との対応:
- 全体所感:

高:
- [ ] 指摘内容（理由と改善案を簡潔に記載）
- [ ] 指摘内容

中:
- [ ] 指摘内容
- [ ] 指摘内容

低:
- [ ] 指摘内容
- [ ] 指摘内容

補足:
- 影響範囲:
- テスト観点:
- CLAUDE.md遵守状況:
- 未確認領域（あれば）

---

## 出力ルール

- 高 → 中 → 低 の順で出力する
- チェックリスト形式で出力する
- 推測は断定しない
- 情報取得不可の場合は明示する
- 各repoごとに独立した結果を出す

---

## 例

入力:

```
/review repo-a:123 repo-b:98 https://notion.so/xxxx
```

処理内容:

- ルートCLAUDE.md読取
- repo-aおよびrepo-bのCLAUDE.md読取
- Notion要件取得
- 各PR情報取得
- 要件照合
- repo単位でレビュー出力

---

## 重要ルール

- ルートCLAUDE.mdは必ず参照する
- 各repo直下CLAUDE.mdは必ず参照する
- Notion取得失敗時は明示する
- diff全件確認不可の場合は未確認範囲を明示する
- 推測ベースの断定を行わない
