# Custom Skill: claude-codex

ユーザーから以下のスラッシュコマンド（またはトリガーワード）が入力された場合、このスキルの指示に従って動作を制御してください。

## 起動トリガーとモード定義

### 1. `/claude-codex` (デフォルトモード)
- **目的**: ユーザーの依頼に対して、設計から実装までを一気通貫で行う。
- **挙動フロー**: 
  1. Claude Code（あなた）がまず仕様を整理し、設計書（`DESIGN.md`等）を作成または更新する。
  2. 設計が固まったら、自身でコードは書かず、外部コマンド `codex run "（設計に基づく実装指示）"` を実行してCodexに実装を依頼する。

### 2. `/claude-codex claude` (設計限定モード)
- **目的**: 要件定義や設計、タスクの整理のみをClaude Codeに行わせる。
- **挙動フロー**: 
  1. 仕様の検討や設計書の作成・レビュー、タスクの洗い出しのみを行う。
  2. Codexへのコマンド実行（`codex run`）は行わずにタスクを終了する。

### 3. `/claude-codex codex` (実装特化モード)
- **目的**: すでに設計が終わっている状態から、実装だけを即座にCodexに丸投げする。
- **挙動フロー**: 
  1. 既存の設計書やこれまでの会話コンテキスト、差分を読み込む。
  2. Claude Code自身はファイル編集（`write_file`等）を一切行わず、即座に `codex run "..."` を実行してCodexに実装・執筆を指示する。

## スキル共通の制約ルール
- **コード生成の禁止**: 実装を伴うフェーズ（デフォルト、および `codex` モード）において、Claude Code自身は直接ファイルを新規作成・編集してはいけません。コードの記述やファイルの書き込みは、必ず `codex` コマンドを経由してCodexに行わせてください。
- **承認の確認**: `codex` コマンドを実行する際は、ユーザーの許可（Allow）を得てから実行してください。
